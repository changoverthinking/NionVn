Dữ liệu cá nhân

NionVN tự động lưu lịch sử, từ yêu thích, danh sách học và ghi chú ngay trên trình duyệt của máy bạn (localStorage) — mở lại app là dữ liệu vẫn còn, không cần nhập lại. Dữ liệu chỉ nằm trên máy bạn, không gửi đi đâu cả. Nút xuất/nhập bên dưới dùng để sao lưu hoặc chuyển dữ liệu sang máy/trình duyệt khác.

🤖 Dịch AI (LibreTranslate)

Tính năng "Dịch AI" trong tab Dịch cần một máy chủ LibreTranslate và (thường là) một API key miễn phí. Lấy key miễn phí tại portal.libretranslate.com, hoặc dùng máy chủ cộng đồng khác/tự host nếu bạn có. Cần có mạng khi dùng — nếu để trống hoặc mất mạng, nút "Dịch (từ điển offline)" vẫn hoạt động bình thường như cũ.

Về NionVN

NionVN là ứng dụng từ điển Nhật-Việt hoạt động hoàn toàn offline, chạy trực tiếp trong trình duyệt — không cần cài đặt, không cần Internet để tra từ, Kanji, ngữ pháp, học flashcard hay luyện JLPT. Phát âm và nhận diện giọng nói sử dụng công nghệ có sẵn của trình duyệt/hệ điều hành.

➕ Thêm từ vào từ điển của bạn

Đang học theo Minna no Nihongo, Quartet, Shin Kanzen Master, TRY! JLPT, Sou Matome, sách thuật ngữ chuyên ngành… hay bất kỳ tài liệu nào? Bạn tự gõ lại từ và ví dụ bạn đang học vào đây — từ sẽ được lưu vĩnh viễn trên máy bạn và xuất hiện trong Tra từ, Từ vựng, Flashcard như từ điển gốc. (NionVN không tự sao chép nội dung sách vì lý do bản quyền, nhưng việc bạn tự nhập từ mình đang học thì hoàn toàn không sao.)

📋 Nhập hàng loạt (CSV)

Mỗi dòng một từ, theo định dạng: Kanji|Hiragana|Romaji|Nghĩa VI|Cấp độ/Nguồn — ví dụ:
頑張る|がんばる|ganbaru|cố gắng|Minna N4

Từ bạn đã thêm

➕ Thêm mẫu ngữ pháp

Gõ lại mẫu ngữ pháp bạn đang học (từ Shin Kanzen Master, TRY!, Sou Matome, Dictionary of Japanese Grammar…) theo lời văn của bạn.

📋 Nhập hàng loạt (CSV)

Mỗi dòng một mẫu, theo định dạng: Mẫu|Ý nghĩa|Cấu trúc|Cách dùng|Cấp độ/Nguồn — ví dụ:
〜たばかり|vừa mới làm gì|V-た + ばかり|Diễn tả hành động vừa hoàn thành|Kanzen Master N3

Ngữ pháp bạn đã thêm

Kiểm tra các mục thiếu thông tin quan trọng (thiếu nghĩa, thiếu cách đọc...).

📤 Xuất dữ liệu

Tải toàn bộ dữ liệu bạn đã thêm/sửa (từ vựng, kanji, ngữ pháp tự thêm) dưới dạng file data.js để lưu trữ hoặc dùng thay thế file gốc.

🔗 Đồng bộ với GitHub

Đẩy trực tiếp dữ liệu bạn tự thêm lên repo GitHub Pages của bạn — không cần tải file rồi kéo-thả thủ công nữa. Cần một Personal Access Token (tạo tại GitHub → Settings → Developer settings → Personal access tokens, chọn quyền "repo"). Token chỉ lưu trên máy bạn, không gửi cho ai khác ngoài GitHub.

Lưu ý: sau khi đồng bộ, để app thật sự dùng file này, cần thêm dòng <script src="data-custom.js"></script> vào index.html trên GitHub — tôi có thể hướng dẫn cụ thể nếu bạn cần.
